## How this tracker is updated

When a deliverable moves forward, update all three places in the same commit:

1. The status and output link in the table above.
2. The status table in [README.md](README.md).
3. The matching card on the [preview index page](index.html)
   (badge, and an "Open"/"View" link once the output file exists).

Also update the "Last updated" date and the progress summary, then commit with
a short English message, for example: `Update delivery status: Job Vacancy page completed`.
